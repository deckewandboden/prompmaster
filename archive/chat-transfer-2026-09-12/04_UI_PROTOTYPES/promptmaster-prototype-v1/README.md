# PromptMaster UI Prototype V1.1

## Start
Öffne `index.html`. Dort gibt es zwei getrennte Einstiege: **Kundenportal** und **netstyle Admin-Backend**.

Direktlinks: `kundenportal.html` und `netstyle-admin.html`.


## Start
`index.html` lokal im Browser öffnen.

## Enthalten
### Kundenportal
- Dashboard
- Mein Team
- Lizenzen
- Geräte
- Weitere Lizenzen kaufen
- Bestellungen & Zahlungen
- Unternehmen
- Einstellungen / 2FA
- Hilfe & Kontakt

### netstyle Backend
- Dashboard
- Kunden
- Lizenzverwaltung
- Bestellungen & Zahlungen
- Produkte & Preise
- E-Mail
- Mollie
- Statistiken
- System & Betrieb
- API & Integrationen
- Datenschutz & Recht
- Auditlog
- Benutzer & Rollen
- Einstellungen

## Bedienung
- Navigation über linke Seitenleiste.
- Oben zwischen Kundenportal und netstyle-Backend umschalten.
- Browserbreite verkleinern: Tablet/Smartphone-Responsive-Ansicht.
- Mein Team: Benutzer hinzufügen und Benutzer verwalten.
- Produkte & Preise: Produkteditor öffnen.

## Hinweis
Dies ist ein klickbarer UI-/UX-Prototyp. Backend, Django, PostgreSQL, Mollie-Webhooks, Microsoft Graph, echtes 2FA und Monitoring sind noch nicht produktiv implementiert.
